# 🌸 HELIOS DESIGN SYSTEM

> "AURA is not designed around windows.
It is designed around projection."

---

# Purpose

HELIOS is the official visual language of AURA.

It defines how information is organized, projected, and experienced.

Unlike traditional desktop interfaces, HELIOS prioritizes presence over interface.

---

# Design Goals

• Calm Intelligence

• Visual Hierarchy

• Organic Motion

• Holographic Projection

• Minimal Cognitive Load

• Premium Experience

---

# Layout Philosophy

Every screen revolves around one anchor.

🌸 Lotus Heart

Everything else exists in orbit.

```
          Intelligence

                ▲

Diagnostics ◀ Heart ▶ Conversation

                ▼

         Mission Control
```

The Heart is never visually challenged.
